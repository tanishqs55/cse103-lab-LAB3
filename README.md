## Overview

This repository contains lab work for **LAB 3** of the
Computer Fundamentals & Career Pathways (CSE103) course at
**K.R. Mangalam University**, Gurugram.

The project demonstrates Git repository management,
GitHub collaboration, Markdown documentation, and
basic API interaction.

## How to Run

Clone the repository:

```bash
git clone https://github.com/tanishqs55/cse103-lab-LAB3.git
```

Navigate to the project directory:

```bash
cd cse103-lab-LAB3
```

Run the Python script:

```bash
python3 main.py
```

## Key Learning Outcomes

- Configured Git identity and initialised local repositories.
- Created commits using meaningful commit messages.
- Connected a local repository to GitHub.
- Pushed and pulled changes using a remote repository.
- Created structured Markdown documentation.
- Practised repository collaboration workflows.
